# BasicEyeClick v0.5

This build keeps the stable v0.3 tracking, calibration, larger bubble and mouse control, and adds a transparent click-through overlay for the test game.

## Controls
- M: mouse control ON/OFF
- D: dwell click ON/OFF
- R: recalibrate
- F: toggle fullscreen for calibration/tracking UI
- ESC: exit

The overlay hides the diagnostic camera window after calibration so the test game remains visible underneath.

## Test game
Run `run_game.bat`. It launches the simple point-and-click test and the tracker. The dwell click is initially OFF; press M, then D.

Dwell time is about 0.8 seconds.
