POINTCLICK TEST - ZONA DE BURBUJA

Esta version mantiene el eye tracker y el overlay de la version anterior.
El cambio esta en el juego de prueba: cada objetivo tiene una zona de asistencia
invisible alrededor. Un click se considera acertado aunque el cursor no caiga
exactamente sobre el circulo visible, siempre que quede dentro de la zona de
asistencia.


Zona de asistencia actual: 90 px adicionales alrededor del objetivo.

Para probar:
1. Ejecutar run_game.bat.
2. Activar M para control del mouse por mirada.
3. Activar D para click cada 0.8 segundos
4. Mirar un objetivo manteniendo la mirada.
5. El click sera aceptado aunque quede algo desplazado del objetivo.
